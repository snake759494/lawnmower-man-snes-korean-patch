# 검증 범위

## 실행 검증 (최종 해시 ROM, 헤드리스 snes9x libretro)
- 콜드 부팅 → 타이틀 로고 → 라이선스 → 프롤로그.
- 그림 표 0~45번을 차례로 표시하는 검사용 변형으로 이야기·구역 진입(플레이어 1)·제작진·엔딩 문장 전 화면 확인. 표 7·18번은 실제 게임에서 쓰지 않는 빈 항목으로 원본에서도 쓰레기 문자가 나옵니다.
- 플레이어 선택(참가 대기 포함), 게임 진입, 일시정지, HUD, 데모 플레이(DEMO MODE).
- 아이템 메시지는 플레이어 DP($0500)의 $6D·$69를 써서 강제로 띄워 확인.
- 문장 화면 이후 게임 화면의 HUD 타일 손상 없음.
- 검증용 에뮬레이터는 모두 종료했습니다.

## 정적 검증
- 공개 도구 재빌드 결과가 릴리즈 ROM과 바이트 단위로 같음.
- xdelta를 원본에 적용한 결과가 릴리즈 ROM과 같음. 체크섬 유효.
- 화면당 한글 최대 55자(한도 127), 모든 줄 32칸 이내, 메시지 16칸 이내.

## 미검증
- 전편 실제 플레이와 실제 진행 중 모든 구역 진입·엔딩 도달.
- 플레이어 2 문장의 실제 진행 화면(빌드 데이터는 생성·검사).
- 게임오버 후 CONTINUE 실제 화면(ROM 그래픽 렌더링으로만 확인).
- 실기(실제 SNES·플래시 카트).
